# Classroom AI Chatbot ✦

An AI-powered full-stack virtual classroom assistant designed to enhance lectures with instant summaries, dynamic pop quizzes, and real-time student Q&A powered by Google Gemini.

## 🚀 Live Deployments

- 🌐 **Landing Page (GitHub Pages)**: [https://aneeshp111.github.io/Classroom-AI-Chatbot/](https://aneeshp111.github.io/Classroom-AI-Chatbot/)
- 💻 **Web Application (Vercel)**: [https://classroom-ai-chatbot.vercel.app/](https://classroom-ai-chatbot.vercel.app/)
- ⚙️ **Backend API (Render)**: [https://classroom-ai-chatbot-backend.onrender.com](https://classroom-ai-chatbot-backend.onrender.com)

## 🧠 Features

- **Smart Summaries**: Students can request instant key point summaries of any lecture material uploaded by the teacher.
- **Instant Pop Quizzes**: Teachers can auto-generate contextual multiple-choice questions and push them live to the whole class.
- **Intelligent Q&A**: A dedicated AI assistant that answers student questions strictly based on the uploaded lecture notes.

## 🛠️ Project Structure

- `/landing-page` & `/docs`: Static landing page website served via GitHub Pages.
- `/frontend`: Vite single-page application deployed on Vercel.
- `/backend`: Node.js/Express server using SQLite deployed on Render.
