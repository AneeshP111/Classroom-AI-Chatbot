# Chatbot Feature Roadmap

## 🚀 Phase 1: MVP (Core Features)
These ensure the chatbot is functional and useful right away:
- [x] **Q&A Assistant**: Answers only from teacher-uploaded notes.
- [ ] **Summarization**: Students can request key points from lectures.
- [x] **Basic Quiz Generation**: Auto-create simple multiple-choice questions.
- [x] **Session Join with Code**: Students connect to live sessions securely.

---

## ⚡ Phase 2: Advanced Features
Once the basics are stable, add features that improve engagement:
- [ ] **Flashcards & Revision Mode**: Generate flashcards from notes.
- [ ] **Analytics Dashboard (Teacher)**: Show which topics students ask about most.
- [ ] **Adaptive Quizzes**: Difficulty adjusts based on student performance.
- [ ] **Interactive Diagrams**: Convert text into flowcharts or visual summaries.
- [ ] **Peer Learning Mode**: Group similar student questions and share answers.

---

## 🌟 Phase 3: Future Expansion
These make your chatbot stand out as a full learning ecosystem:
- [ ] **Gamification**: Badges, leaderboards, and rewards for participation.
- [ ] **Voice Integration**: Students ask questions verbally during lectures.
- [ ] **Offline Mode**: Cached notes for students without internet access.
- [ ] **AI Insights for Teachers**: Highlight weak areas in student understanding.
- [ ] **Collaboration Tools**: Group discussions moderated by AI.
